- A `bash` command that waits for CI by polling (a `for`/`while`/`until` loop or `watch` around `gh run`, `gh workflow` or `gh pr checks`, `gh run watch`, `gh pr checks --watch`, or an earlier `sleep` before the check) keeps its result and gets a note with the native `wait` call to use instead (#1540). The 40-hex head and the workflow name are filled in when the command or its output names them, and the note never blocks: the command runs and reports its own exit status. `oxa.bash.ciPollHint` (`true` by default) turns the note off; user settings only. See [tools.md](https://github.com/oxstack/ox-llm/blob/main/oxa/docs/pages/tools.md#ci-polling).
