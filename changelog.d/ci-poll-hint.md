- A `bash` command that waits for CI by polling (a loop or `watch` around `gh run`, `gh workflow` or `gh pr checks`, `gh run watch`, `--watch`, or an earlier `sleep`) keeps its result and gets a note with the native `wait` call to use instead (#1540). `oxa.bash.ciPollHint` (on by default) turns it off; the `oxa_result` record carries `ci_polls`. The `wait` tool description now names `ci` and `pr_merged` first with an example, so the tool list changes once. See [tools.md](https://github.com/oxstack/ox-llm/blob/main/oxa/docs/pages/tools.md#ci-polling).
