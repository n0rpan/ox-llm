- A `deliverable` tool lets the model record the file a request asks for and check it from the guarded file view: existence, size and the private-path floor, never the content. At the end of the run, declared files are checked once more and the run ends with a compact record (`verified-now`, `missing`, `unverified`); at the run's limit the wrap-up message names a declared file that is not on disk. Evidence only: no finish gate, no exit-code change, and a run that declares nothing is unaffected.
