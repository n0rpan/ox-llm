- One finish decision before a run or goal ends: a run that changed files and ran no passing check afterwards, and a goal that completes (or a headless run that ends) while background jobs still run, each get one extra turn, then end with a warning and a record. `oxa.done.proveIt` and `oxa.done.waitForJobs` (both on by default) turn them off; the `oxa_result` record carries `proved` and `jobs_running`.
- `bash` now sees a detached part anywhere in a command (`&` outside quotes, `nohup`, `setsid`, `disown`), says that its output and exit status are not in the result and what happens to the process, and such a call never counts as a passing check.
