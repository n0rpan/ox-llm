- A goal can be resumed from any state except done or canceled, in the same session, by `/goal resume` and by the a2a resume (which now starts one continuation run); a run that fails leaves its pursuing goal paused with the error code as the reason (#1565). An exhausted budget answers `goal_budget_exhausted`.
- An idle goal no longer loops at full speed: after two replies without a tool call it gets one nudge naming its three moves, then oxa waits itself before each next request (`oxa.goal.idleBackoffSeconds`, default 60, doubling, recorded, `0` off); a reply that matches the output schema is recorded as an answer and followed by a `wait` or `goal_done` prompt instead of repeating (#811, #1966). `oxa.goal.idlePause` is unchanged.
