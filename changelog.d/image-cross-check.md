- A run that read an image file and changed files, with no check since the image was read, gets one extra turn asking for a concrete independent cross-check of its reading (re-render and diff against the source, an independent reader such as OCR, or an invariant), or to name the unverified image-derived claim in the final message; it then ends with a warning and a record. `oxa.done.imageCrossCheck` (on by default, user settings only) switches it; the `oxa_result` record carries `image_unverified`. Runs that read no image or changed no file are never asked.
