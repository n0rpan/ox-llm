- Lead web transport: the stylesheet and script are served at content-hashed URLs (`/a/<sha8>/style.css`, `/a/<sha8>/live.js`) with a one-year immutable cache, so a repeat visit loads neither asset. Pages and fragments carry an `ETag` and answer `304 Not Modified` to a client that already has them, and pages, assets and fragments are gzipped when the client accepts it (Home is about 1.7 KB on the wire). Every request is still authorized before any of this, and a `304` carries the same security headers and `no-store` as the page.
