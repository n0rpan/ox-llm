- The owner confirm broker is reached through an inherited descriptor (`OXA_CONFIRM_FD`) instead of a socket path. The sandbox no longer mounts a socket, masks `/run` or denies nested user namespaces for it, so sockets under `/run` that you allow are visible again and the agent directory location no longer matters. Lane pushes, `oxa send --approve` and `oxa work --publish` ask through one verified path: inside the OS sandbox, where the session's oxa cannot be verified, they answer none and say to run from a terminal or an unsandboxed session.
