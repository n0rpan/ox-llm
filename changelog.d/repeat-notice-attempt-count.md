- The repeat guard writes its change-of-approach suggestion once, on the first note of a loop. Each later note is shorter, carries the attempt count of the call and points back to that suggestion, so a stuck model is not fed the same paragraph again and a healthy turn is unchanged. The call still runs, no new refusal, cap or provider call is added, and the one warning per run stays. See [tools.md](https://github.com/oxstack/ox-llm/blob/main/oxa/docs/pages/tools.md#repeated-calls).
