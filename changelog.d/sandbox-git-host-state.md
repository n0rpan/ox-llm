- The sandbox leaves your `.git` as it found it and lets ordinary git config writes through (#276, #639): the empty mount-point files and directories bwrap needs in the host `.git` (`commondir`, `gitdir`, `config.worktree`, `hooks`) are recorded and removed when the session ends (also after a killed oxa, and never while another running session still has them mounted), and `git branch -m` and `git config user.name` work because an existing `config` is no longer bound read-only. After each command the sandbox compares `config` with what it was: changes to the keys of the new user-only `oxa.sandbox.gitConfigAllow` (default `branch.*`, `user.*`, `remote.*.fetch`) stay, any other change is restored with a note in the command output.
