- The bash sandbox builds one ordered mount plan per command, and the file tools use the same view (#955, #486): `write` and `edit` still write where you ask and now add a note when sandboxed bash cannot see that path (hidden), pointing at `oxa.sandbox.readPaths` / `oxa.sandbox.writePaths`. The session `/tmp` scratch directory records its owner, so a directory whose pid was reused is pruned, and a command's output carries one warning line when it grows past the new user-only `oxa.sandbox.scratchWarnSize` (default `20GiB`, `off` disables; never blocks).
