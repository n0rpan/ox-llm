syntect licence (third-party component of the oxa binary)
=========================================================

The oxa binary links the syntect syntax-highlighting library (crates.io, syntect 5; the exact
version is pinned in Cargo.lock) with the features `default-syntaxes` and `regex-fancy`. That
embeds syntect's precompiled default syntax set (assets/default_newlines.packdump and
default_nonewlines.packdump in the crate), which is built from the Sublime Text syntax
definitions of the sublimehq/Packages repository. syntect's bundled colour themes are NOT
compiled in (the `default-themes` feature is off; oxa maps scopes to its own themes).
